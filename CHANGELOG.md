# Changelog

## 1.4.0 (candidate)
- Require genuine Hugeicons for new icon-bearing Systra UI and verify exports, build and render.
- Add composition alternatives, practical art direction and original code-based visual recipes.
- Add blocking visual release gates, screenshot-led correction and controlled A/B regression cases.
- Preserve scoped brand overrides, accessibility and the photo-free public package.
- Candidate changes are not evidence of visual A/B success; publish only after independent evaluation.

## 1.3.0 · 2026-11-13
- Consolidated design, critique and refinement into a single installable skill.
- Preserved the full review and repair workflows as internal references.
- Reworked public documentation around art direction and interface craft.
- Simplified the release to one skill and one ZIP download.

## 1.2.0 · 2026-11-13
- Added optional GSAP, ScrollTrigger and Lenis integration guidance with ticker synchronization, teardown and accessibility fallbacks.
- Added explicit copy, subtle-radius, borderless, shadow-free and Hugeicons defaults for new Systra-style work.
- Added practical entrance and scroll animation guidance, including reduced-motion and performance checks.
- Aligned the design, review and repair skills with the new visual defaults without overriding existing brands.

## 1.1.0 · 2026-11-13
- Expanded the public build skill with concrete architecture, hierarchy, imagery, motion and QA decision recipes.
- Explicit photo-free distribution policy: project photography remains supported, bundled reference imagery is not required.
- Added a validation test that rejects image assets and embedded images in skill folders.

## 1.0.0 · 2026-11-09
- First public, original Systra Taste agent-skill collection.
- Separates building, evidence-backed review and isolated redesign/repair.
- Defines independent workflows, installation commands and objective release gates.
- Includes example scenarios and a no-spam discoverability plan.

# References and concept: the step that prevents the AI look

A page looks AI-made when it is the average of everything: the same skeleton, the same type sizes, the same cards, only the colors change. Three test pages built straight from earlier versions of this skill (painter, hair salon, dentist) were the same page three times. Real references and one idea per client fix that.

## 1. Reference hunt (before any layout)

Look at 3 to 5 strong, real sites from the same industry. Use the browser if one is available; a list of names from a search is not enough, you have to see them.

- Framer Marketplace: `https://www.framer.com/marketplace/search/?q=<industry in English>` (dentist, painter, hair salon, physiotherapy, bakery ...). The thumbnail grid is enough for a first pass.
- Awwwards or Siteinspire for the industry, Pinterest boards the user shares, and any references the user sends. The user's own references win.

Write down three moves, each with its source, for example:
- "Alder: photo behind fluted glass, headline bottom left."
- "Dental Point: one sentence, two words, an object placed between them."
- "Dentelle: one giant object cropped by the bottom edge."

Take moves, never a whole layout, never text or images.

## 2. Concept in one sentence

Name the idea the page is built on. It must only fit this business. "Clean and modern", "calm and trustworthy" or "premium" are moods, not concepts.

| Business | Concept | Signature moment |
| --- | --- | --- |
| Dentist | Fluted glass is the practice's material; fear gets blurry. | The word "Angst" in the headline sits behind fluted glass. |
| Dentist | The appointment card everybody knows from the practice. | The first visit shown as a slightly rotated paper appointment card. |
| Painter | The page is a paint fan. | Choosing a swatch recolors the wall in the hero photo. |
| Hair salon | Before the mirror, after the mirror. | A cut line runs through the hero; dragging it reveals the new cut. |

## 3. Signature moment

Exactly one element per page that no template would have: an interaction, a typographic idea, a material, a real object from the business. Everything else stays quiet so it can shine.

## 4. Vary the skeleton

- No two neighbouring sections use the same structure. Mix: full-width type, an object on a panel, an oversized number, a split, a list in large type.
- One oversized typographic moment per page (headline, phone number, a single word) at least twice the size of the other headings.
- The service-site blocks are parts, not a page. Used all together in their order they rebuild the AI look.

## AI tells (reject when you see them)

- Text column left, gradient panel with floating white cards right, as the hero of every project.
- "Heading left, content right" for three or more sections in a row.
- Every heading the same size and weight; small grey paragraph under every heading.
- Four numbered steps, four equal cards, three equal team portraits.
- Chat bubbles or dashboard cards as decoration when the business has no such moment.
- Nothing on the page that refers to the real place, people or objects of this business.

Final test: point to the one thing on the page that a template would not have. If there is none, go back to the concept.

# Systra Taste

**A sharper eye for digital interfaces.**

Systra Taste is one open skill for considered art direction, interface craft and motion. It brings thoughtful design decisions into real web projects, from the first composition to the last interaction detail.

Not a theme pack. Not a fixed aesthetic. The point is to make the work feel deliberate, appropriate and finished.

[![skills.sh](https://skills.sh/b/systra-tools/systra-taste)](https://skills.sh/systra-tools/systra-taste)

## Install

One skill. One command. Compatible with Claude Code, Cursor, Codex and other coding agents that support `SKILL.md`.

```bash
npx skills@latest add systra-tools/systra-taste
```

Choose the agent and installation scope when prompted. Global installation is also supported with `-g`. Systra Taste works **without any Systra account**.

## What it does

**Art direction.** Give a page one clear idea. Establish a hierarchy and a rhythm that suit the content, rather than dressing a generic layout in gradients.

**Design critique.** Look closely at what is already there. Identify weak composition, confusing typography, inconsistent interaction or unnecessary visual noise. A critique stays read-only unless changes are requested.

**Considered refinement.** Rework an interface with its content and behavior intact. When multiple directions are requested, explore genuinely different layouts in safe previews before integrating the chosen one.

These are capabilities of **the same Systra Taste skill**, not separate products or installations.

## The Systra signature

For new work without stronger existing brand rules:

- Specific, concise copy without em dashes.
- Clear typography and content-led composition.
- Slightly rounded corners, generally 6 to 12 px.
- No decorative borders around boxes and no box shadows. Functional focus and form boundaries remain visible.
- Consistent Hugeicons where iconography genuinely helps.
- Refined entrance animation and selective scroll-driven transitions.
- Optional GSAP, ScrollTrigger and Lenis for more demanding motion.

A brand's established system always takes precedence over these defaults.

Explore the [visual signature](skills/systra-taste/references/visual-signature.md), [motion patterns](skills/systra-taste/references/motion-patterns.md) and [Lenis + GSAP reference](skills/systra-taste/references/lenis-gsap.md).

## Put it to work

**Design**

```text
Use Systra Taste on this project. Refine the service page
with stronger hierarchy, considered type and meaningful motion.
Work within the existing brand. Check mobile and accessibility.
```

**Critique**

```text
Use Systra Taste to review this landing page.
Find the three most important visual or interaction issues,
with evidence and concrete recommendations. Do not change code.
```

**Refine**

```text
Use Systra Taste to improve this existing hero.
Keep the content, links and behavior. Show distinct layout
directions in an isolated preview before editing production.
```

The [example critique](examples/review-report.md), [hero refinement](examples/hero-repair.md) and [evaluation cases](examples/evaluation-cases.md) illustrate the approach.

## Working principles

Inspect the real codebase, content and existing components first. Use approved imagery and honest proof. Keep controls, navigation and data as semantic code.

Test at mobile and desktop sizes, including keyboard use and reduced-motion settings when tooling is available. If a visual test was not run, say so. Good design is about decisions that survive contact with the actual product.

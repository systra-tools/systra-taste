# Page Rhythm: A Short Composition Guide

Not every website needs every section. Every added section must answer a new question.

| Question | Useful section form | Risk to avoid |
| --- | --- | --- |
| What is this? | Editorial statement with a real product/person/process focal point | Abstract gradient orb without meaning |
| How does it work? | One clear step sequence or usable interface demo | Three identical feature cards with vague labels |
| Why believe it? | Contextual results, workflow proof, credible examples | Fake customer logos and fabricated figures |
| Is it for me? | Specific use cases or comparative states | Generic industry list with no relevance |
| What can I do? | One strong action in appropriate context | Several competing CTAs |

## Three composition strategies

**Editorial:** One decisive headline and one supporting scene, followed by content arranged for reading. Use for complex, meaningful offers where substance matters more than dashboard screenshots.

**Product-evidence:** Show a real product interface as the largest object, then explain its value through callouts and progression. Use for developer tools and software whose interface is the proof.

**Spatial narrative:** Use scroll to move among meaningful states of one visual subject. Works for a focused story, not every agency portfolio. Always provide static fallbacks and respect reading time.

## Bad vs useful direction

Avoid: "Create a modern landing page with a gradient heading, cards, nice shadows and smooth animations."

Better: "Lead with the actual search-to-code workflow. Make one real component preview occupy the hero's visual half. Below it, show a selected search result, the source code that gets copied and the resulting page. Keep pricing below the explanation; do not copy the same grid three times."

**Divergent options must change architecture and focal subject.** A different accent color is not a new design concept.

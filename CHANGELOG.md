# Changelog

## 3.0.0 (candidate)
- Add a deterministic, dependency-free component planner and source materializer for five offline jobs.
- Validate inputs, reject ambiguous requests, never overwrite existing project directories, and preserve the actual original components.
- Suggest authorized MCP queries without claiming remote integration.
- No new public release; visual quality and live MCP remain separate gates.

## 2.2.0 (candidate)
- Component-first routing: existing project, authorized Systra MCP, then original offline React source.

- Preserve modular context, no-photo policy and premium access boundaries.
- Visual and latency advantage in independent generation remains unverified.

## 2.1.0 (candidate)
- Short core with job-based reference routing; load only the relevant recipe, with a bounded initial context.
- Four original interactive React/Tailwind recipes: scene markers, real signal transformation, selectable offer ledger and editorial gallery.
- Avoid repetitive serif-accent defaults; keep Hugeicons, accessibility, authorized imagery and honest visual QA.
- Retain the full optional atlas and private preview policy. Design improvement and runtime remain subject to an independent A/B benchmark.

## 2.0.0 (candidate)
- Reference-first design workflow, with six art directions and 34 curated static preview observations.
- Twenty motion and fifteen control recipes, including original implementation primitives.
- Mandatory visual-reference evidence and screenshot-led revision for substantial design work.
- Public text-only index; private visual atlas remains local, and premium source remains protected.
- Visual A/B improvement remains unverified; no stable release has been published.

## 1.4.0 (candidate)
